# DeatHUD

A HUD and minimap plug-in for **LET IT DIE**, built on [Mod Drive 9000](https://github.com/kevinsnagy-del/ModDrive9000).

- The minimap builds its own area map, so you no longer have to open the area map first.
- Minimap background, fog and icon colours can be changed. This uses pre-baked colour textures and a greyscale icon sheet, added by its pack.
- Its options are under **Options, then Mod Drive 9000, then DeatHUD**.

## Install

1. Install [Mod Drive 9000](https://github.com/kevinsnagy-del/ModDrive9000) first.
2. Download `DeatHUD-<version>.zip` from [Releases](../../releases), close the game, and unzip it into the LET IT DIE folder.
3. Run `ModDriveInstaller\Install.bat` again. It adds DeatHUD's textures to your game files, after backing them up.

**Updates:** run `ModDriveInstaller\Update.bat`. **Remove:** run `ModDriveInstaller\Remove.bat` and type `deathud`.
